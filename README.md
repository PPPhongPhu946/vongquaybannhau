# 🍺 Vòng Quay Bàn Nhậu (Drinking Roulette)

Trò chơi **Vòng Quay Bàn Nhậu** giao diện **Dark Mode + Neon Bar** sôi động, gói gọn trong **1 file `index.html` duy nhất**, tối ưu hóa cho điện thoại đặt giữa bàn nhậu và máy tính.

## ✨ Tính năng nổi bật

- 🎨 **Giao diện Bar Neon (Mobile-First)**: Hiệu ứng đèn LED nhấp nháy quanh vòng quay, màu sắc Neon rực rỡ.
- 🎡 **Vòng quay HTML5 Canvas chuẩn Retina**: Vật lý quay `ease-out` 4.5–5 giây mượt mà, tự động phát hiện đinh chốt gẩy kim chỉ ở đỉnh 12 giờ.
- 🔊 **100% Web Audio API**: Tự tổng hợp tiếng "tạch tạch" theo tốc độ quay, tiếng kèn Fanfare chiến thắng và tiếng vỗ tay/pháo nổ (không cần file `.mp3` ngoài).
- 🏆 **Đếm Ly & Bảng Phong Thần Tửu Lượng**:
  - Quản lý danh sách chiến hữu trên bàn, tự động chuyển lượt quay.
  - Tự động phân tích kết quả ô trúng thưởng để cộng ly cho người quay, người bên trái, bên phải, cả bàn hoặc chọn đồng đội uống cùng.
  - Xếp hạng tửu lượng theo thời gian thực (*Thần Cồn*, *Thánh Né Đạn*, *Tiên Tửu Hạ Phàm*...).
- ⚙️ **Tùy chỉnh linh hoạt & `localStorage`**: Thêm, sửa trực tiếp, xóa ô thử thách hoặc khôi phục mặc định mà không sợ mất dữ liệu khi tải lại trang.

## 🚀 Cách chạy

Chỉ cần mở trực tiếp file `index.html` trên trình duyệt hoặc bật **GitHub Pages** trong phần Settings của repository để chơi online trên điện thoại!
